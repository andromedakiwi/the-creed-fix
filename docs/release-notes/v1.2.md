First public test release of the unofficial patch for **The Creed (1999)** – by Andromeda Kiwi + Claude.

**Install:** extract `TheCreed_UnofficialPatch_v1.2.zip` into your game folder (Hardware Accelerated version, `Creed.exe` v1.6 build 160) and run `Creed.exe`.

### Fixes
- Starts in hardware accelerated mode without the original installer's registry key
- Menu backgrounds and cursor trails fixed
- Original 1999 crash a few seconds into gameplay fixed (depth-buffer rectangle clipping)
- Hybrid No-CD: `Extras\CopyCDs.bat` copies the CD files once; without them the game asks for the CD as before
- CD music via ogg-winmm (`Music\Track02.ogg` … `Track19.ogg`, rip from CD 1)
- dgVoodoo2 2.87.6 with a tested full-screen configuration

### Known issues
Don't Alt+Tab while playing; intro videos play in a window; campaign not yet tested to the end. Details in the README and [docs/TECHNICAL.md](https://github.com/andromedakiwi/the-creed-fix/blob/main/docs/TECHNICAL.md).

Please report problems in [Issues](https://github.com/andromedakiwi/the-creed-fix/issues) – crash dumps very welcome.
