Release v2.0 of the unofficial patch for **The Creed (1999)** – by Andromeda Kiwi + Claude.

**Your `Creed.exe` is no longer modified.** All the fixes are now applied in memory, at start-up, by a small open-source `dinput.dll` built from this repository ([src/creedfix](https://github.com/andromedakiwi/the-creed-fix/tree/main/src/creedfix)). It checks that `Creed.exe` is the original v1.6 build 160 before touching anything and writes what it did to `creedfix.log`.

**Install:** extract `TheCreed_UnofficialPatch_v2.0.zip` into your game folder (Hardware Accelerated version, original `Creed.exe` v1.6 build 160) and run `Creed.exe`.

**Upgrading from v1.x:** put your original `Creed.exe` back (`Creed.exe.original` or your backup). A v1.x executable is detected and the patch tells you so.

### Why
- No more distributing a modified copy of the game's executable
- The original `Creed.exe` is a long-known file, so Windows 11 **Smart App Control** should no longer block it (the new `dinput.dll` is not code-signed yet – please report if it is blocked)

### Fixes (unchanged from v1.5)
- Starts in hardware accelerated mode without the original installer's registry key
- Menu backgrounds; original 1999 gameplay crash and edge trails
- Alt+Tab / Ctrl+Alt+Del: pauses when you leave, resumes when you return, cursor included
- Hybrid No-CD (`Extras\CopyCDs.bat`), CD music via ogg-winmm with a working volume slider
- *Intro Videos* option in Configuration to skip the startup video
- dgVoodoo2 2.87.6 with a tested configuration

### Known issues
- Campaign not yet tested to the end; multiplayer untested

Details in the README and [docs/TECHNICAL.md](https://github.com/andromedakiwi/the-creed-fix/blob/main/docs/TECHNICAL.md). Please report problems in [Issues](https://github.com/andromedakiwi/the-creed-fix/issues) – crash dumps and `creedfix.log` very welcome.
