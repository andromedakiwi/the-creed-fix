Bug-fix release of the unofficial patch for **The Creed (1999)** – by Andromeda Kiwi + Claude.

**Install:** extract `TheCreed_UnofficialPatch_v1.4.zip` into your game folder (Hardware Accelerated version, `Creed.exe` v1.6 build 160), overwrite, and run `Creed.exe`.

### New in v1.4
- No more cursor or character trails along the screen edges (the game's dirty rectangles are now clipped to the screen for the background restore too, not only for the depth copy)
- The cursor no longer disappears after Alt+Tab: mouse movement made while the game was paused is discarded when you return

### Everything from earlier versions
- Starts in hardware accelerated mode without the original installer's registry key
- Menu backgrounds fixed; original 1999 gameplay crash fixed
- Alt+Tab / Ctrl+Alt+Del: the game pauses when you leave and resumes when you return
- Hybrid No-CD (`Extras\CopyCDs.bat`), CD music via ogg-winmm, dgVoodoo2 2.87.6 with a tested configuration

### Known issues
- Windows 11 **Smart App Control** may block `Creed.exe` ("could not verify its publisher") – the executable is not code-signed yet
- Intro videos play in a window; campaign not yet tested to the end

Details in the README and [docs/TECHNICAL.md](https://github.com/andromedakiwi/the-creed-fix/blob/main/docs/TECHNICAL.md). Please report problems in [Issues](https://github.com/andromedakiwi/the-creed-fix/issues) – crash dumps very welcome.
