Release v1.5 of the unofficial patch for **The Creed (1999)** – by Andromeda Kiwi + Claude. Tested through several missions on Windows 11.

**Install:** extract `TheCreed_UnofficialPatch_v1.5.zip` into your game folder (Hardware Accelerated version, `Creed.exe` v1.6 build 160), overwrite, and run `Creed.exe`.

### New in v1.5
- **Music volume works:** the in-game music slider now controls the ambient soundtrack (it used the sound card's analogue CD-audio mixer line, which modern PCs don't have)
- **Skip the intro video:** in the launcher's *Configuration*, untick **Intro Videos** (formerly *Intro Attract*) to go straight to the game menu

### Everything from earlier versions
- Starts in hardware accelerated mode without the original installer's registry key
- Menu backgrounds fixed; original 1999 gameplay crash and edge trails fixed
- Alt+Tab / Ctrl+Alt+Del: the game pauses when you leave and resumes when you return, cursor included
- Hybrid No-CD (`Extras\CopyCDs.bat`), CD music via ogg-winmm, dgVoodoo2 2.87.6 with a tested configuration

### Known issues
- Windows 11 **Smart App Control** may block `Creed.exe` ("could not verify its publisher") – the executable is not code-signed yet
- Campaign not yet tested to the end

Details in the README and [docs/TECHNICAL.md](https://github.com/andromedakiwi/the-creed-fix/blob/main/docs/TECHNICAL.md). Please report problems in [Issues](https://github.com/andromedakiwi/the-creed-fix/issues) – crash dumps very welcome.
